# محرك صور المنتجات من جوجل + تدقيق أمان قاعدة البيانات

## ما هو مُنفَّذ فعلاً (تم التحقق منه الآن)

- **الأسرار**: `GOOGLE_API_KEY` و`GOOGLE_CX_ID` مخزّنان على الخادم ويُقرآن داخل الـ handler فقط — لا يوجد أي مفتاح مكتوب في الكود.
- **دالة الخادم** `src/lib/ai/product-image-search.functions.ts`: استعلام `"{الاسم} دواء علبة"` ثم `"{الاسم} صيدلية"` عند الفشل، مع `searchType=image`, `imgType=photo`, `safe=active`، تصفية الامتدادات `.jpg/.png/.webp`، ترتيب حسب الدقة مع أفضلية للنطاقات الصيدلانية، دفعات بحجم 8 وتأخير 300ms، وبدون رمي استثناء عند عدم وجود صورة (يُسجَّل `skipped` ويستمر).
- **واجهة `/admin-image-queue`**: زر التحديث، مؤشر تقدّم حي، خيار إعادة تحديث الصور الموجودة، وتقرير نهائي بالمحدَّث/المتخطّى وسبب التخطي.
- **أمان `hc_doctors`**: صلاحية القراءة على مستوى الجدول مسحوبة من `anon` و`authenticated`؛ `qr_token` غير ممنوح لأي منهما (service_role فقط)؛ `phone_e164` ممنوح لـ `authenticated` فقط. هذا البند مكتمل ولا يحتاج تغييراً.

## الفجوات المتبقية — وهي ما سيُنفَّذ

### 1. اسم متغيّر معرّف محرك البحث
الطلب يذكر `GOOGLE_SEARCH_ENGINE_ID` / `GOOGLE_CSE_ID` بينما المخزَّن حالياً `GOOGLE_CX_ID`.
سأجعل الدالة تقرأ أول قيمة متاحة بالترتيب: `GOOGLE_SEARCH_ENGINE_ID` ← `GOOGLE_CSE_ID` ← `GOOGLE_CX_ID`، فلا ينكسر شيء أياً كان الاسم المستخدم مستقبلاً.

### 2. إلغاء حقيقي عبر AbortController
حالياً زر «إيقاف» يوقف الدفعات التالية فقط، والدفعة الجارية تكمل حتى نهايتها.
- تمرير `signal` من `AbortController` إلى استدعاء دالة الخادم، وإلغاؤه فوراً عند الضغط على «إيقاف».
- تجاهل خطأ الإلغاء وعرض التقرير الجزئي لما تم فعلاً بدل رسالة خطأ.
- إعادة ضبط الـ controller مع كل تشغيل جديد.

### 3. رسالة واضحة عند فشل مفتاح جوجل
اختبار المفتاح الحالي ضد Custom Search API يعيد 401 «API keys are not supported by this API». سأحوّل رد 401/403 من جوجل إلى رسالة عربية مفهومة في الواجهة: «مفتاح جوجل غير صالح أو Custom Search API غير مُفعّل» بدل عرض نص الخطأ الخام.

## تفاصيل تقنية
- التعديلات محصورة في ملفين: `src/lib/ai/product-image-search.functions.ts` و`src/routes/_authenticated/admin-image-queue.tsx`.
- لا توجد أي هجرة قاعدة بيانات — بند الأمان مُحقَّق مسبقاً.

## ملاحظة تحتاج إجراءً منك
لكي يعمل الزر فعلياً: أنشئ مفتاح API من Google Cloud مع تفعيل **Custom Search API** (يبدأ عادةً بـ `AIza`) وحدِّث السر `GOOGLE_API_KEY`. المفتاح الحالي مرفوض من جوجل.
