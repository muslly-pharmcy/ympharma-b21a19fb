# Refero public style references

For design tasks, use **research first**, then build. This skill is a pointer to the central index rather than a hidden copy of the 2,000+ styles claimed by Refero.

## Evidence and sourcing
- Source: https://styles.refero.design/
- Central index: https://github.com/muslly-pharmcy/everything-claude-code/tree/skills/refero-styles-catalog-20261117/skills/refero-style-reference
- Public sitemap: https://styles.refero.design/sitemap.xml
- Curated Refero MCP may return `NO_SUBSCRIPTION`; when it does, use public pages through Firecrawl and never bypass paid access.

## Procedure
1. Identify the screen to improve and target device, language direction, interaction and accessibility needs.
2. Search 3–5 suitable website styles from the central reference catalogue. Screens and flows require separate research; marketing style references are **not** dashboard or POS UX proof.
3. For 2–4 promising styles, inspect the current publicly accessible style detail pages, including color roles, fonts, spacing, component hierarchy and motion guidance.
4. Create a reference lock: dominant direction, supporting traits, exact source links, explicit exclusions, typography, color roles and density.
5. Produce an original RTL-ready `DESIGN.md` adapted to the project; preserve existing brand identity, grid-first invoice input and keyboard navigation.
6. Test focus order, keyboard interaction, contrast, reduced motion, mobile/tablet/desktop and loading/error/empty states.
7. Do not alter production source, release pipelines, accounting, business logic or database without explicit implementation instructions and passing tests.
