# Arabic RTL enterprise UI

- Use semantic keyboard-friendly grids/tables for sales, purchases, invoices and ledgers; cards for summaries.
- Isolate LTR numbers, currency, codes, barcodes and dates in RTL layouts.
- Ensure accessible focus, error recovery, keyboard navigation, and dense but legible Arabic typography.
- Respect responsive Windows, Android, iPad and web, with 360/768/1366 viewport testing.
- Moderate glass and 3D effects must honor reduced-motion and avoid layout jank.
- Verify dark/light themes, network failures, performance, permissions and no regression to financial actions.
- Only claim UX improvements after screenshots and observed tests.
