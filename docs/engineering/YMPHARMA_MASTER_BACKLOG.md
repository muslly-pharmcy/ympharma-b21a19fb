# سجل الأعمال الرئيسي — YmPharma

**تاريخ التثبيت:** 2026-10-10  
**قاعدة الترتيب:** أوقف أولاً المخاطر التي قد تفسد المخزون أو تسمح بعبور حدود المؤسسة أو تعطل checkout. لا تُعلن أي بند محلول إلا بدليل اختبار يطابق معايير قبوله.

## تعريف الأولوية

- **P0 — مانع إطلاق:** خلل صلاحية/عزل أو سلامة مالية/مخزون، أو إعداد نشر يمنع تشغيل المنتج على الوجه المقصود.
- **P1 — قدرة أساسية ناقصة:** مسار العمل غير مكتمل أو غير مختبر بحيث لا يفي بوعد الوحدة.
- **P2 — تحسين تشغيلي/جودة:** وصول، offline، تقارير، مراقبة، وتجارب قبول غير حرجة بعد حسم P0.

## ترتيب التنفيذ المقترح

1. حسم B-01 إلى B-06 على فروع مستقلة، وإضافة اختبارات DB سلبية قبل دمجها.
2. إغلاق B-08 (PR #14) وB-24 بعد نجاح CI، مع إبقاء migrations غير مطبقة في الإنتاج.
3. توحيد RBAC/branch scopes وidempotency (B-04/B-05/B-09)، ثم بناء قبول checkout وinventory.
4. استكمال POS والمشتريات والتأمين والوصفة والمحاسبة بوحدات صغيرة ذات contracts واختبارات مستقلة.
5. بعد نجاح كل بوابات القبول، تنفيذ مراجعة إصدار/نسخ/استعادة ثم طلب موافقة منفصلة لأي نشر أو تغيير نطاقات.

**قاعدة الإغلاق:** لا يغلق بند بوصفه محلولاً إلا بمرجع commit/PR، واختبار يثبت معيار القبول، وبيان واضح إذا كان الاختبار محلياً أو على staging أو إنتاج.
