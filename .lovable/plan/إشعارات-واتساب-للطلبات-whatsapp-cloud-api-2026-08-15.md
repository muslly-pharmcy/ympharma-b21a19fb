# إشعارات واتساب للطلبات (WhatsApp Cloud API)

## ملاحظة أمنية مهمة
لصقتَ مفتاح الوصول (Access Token) في المحادثة. سيُخزَّن كسرّ على الخادم فقط ولن يُكتب في الكود.
يُفضّل تدويره (إنشاء توكن جديد) من Meta بعد التنفيذ لأنه ظهر في نص المحادثة.

## ملاحظة معمارية
المشروع لا يستخدم Supabase Edge Functions للمنطق الداخلي؛ الخلفية تعمل عبر دوال الخادم المدمجة
في التطبيق نفسه (نفس النطاق، أسرع، بدون نشر منفصل). سأبني نفس الوظيفة المطلوبة بالضبط
باسم `send-whatsapp-notification` لكن كدالة خادم داخلية بدل Edge Function.
كل الطلبات ستذهب إلى `https://graph.facebook.com/v20.0/1261889173677539/messages` بترويسة Bearer.

## ما سيتم بناؤه

### 1. الأسرار
- `WHATSAPP_ACCESS_TOKEN` (التوكن الذي أرسلته)
- `WHATSAPP_PHONE_NUMBER_ID` = 1261889173677539
- `WHATSAPP_WABA_ID` = 1942791503052210

### 2. مُرسِل الرسائل (خادم فقط)
ملف `src/lib/whatsapp/send.server.ts`:
- تطبيع رقم الهاتف اليمني إلى صيغة دولية (967…) باستخدام منطق الهواتف الموجود.
- إرسال رسالة نصية عبر Graph API v20.0 مع مهلة زمنية ومحاولة إعادة واحدة.
- تسجيل كل محاولة (نجاح/فشل + معرّف الرسالة) في سجلات النظام دون كشف التوكن.
- لا يرمي استثناءات تُفشِل الطلب: يعيد `{ ok, messageId?, error? }`.

### 3. إشعار تلقائي عند إنشاء الطلب
- ربطه داخل `placeOrder` في `src/lib/storefront.functions.ts` بعد نجاح عملية الدفع/الحجز،
  بنفس أسلوب جسر CRM الحالي (best-effort، لا يعطّل الطلب أبداً عند فشل واتساب).
- نص الرسالة بالعربية RTL يتضمن: رقم الطلب، الإجمالي بالعملة، عنوان التوصيل، حالة الطلب،
  واسم الصيدلية.
- يُحترم مفتاح تشغيل/إيقاف في لوحة التحكم قبل الإرسال.

### 4. زر اختبار في لوحة الإدارة
صفحة جديدة `/control-tower/whatsapp` (ضمن مركز الإدارة المحمي):
- حقل رقم هاتف + حقل نص اختياري + زر «إرسال رسالة اختبار».
- عرض النتيجة: نجاح مع معرّف الرسالة، أو رسالة خطأ عربية واضحة (توكن منتهٍ، رقم غير مسجّل،
  خارج نافذة الـ24 ساعة… إلخ).
- مفتاح تفعيل/تعطيل إشعارات الطلبات.
- محمي بصلاحية المدير فقط عبر التحقق من الدور على الخادم.

## تفاصيل تقنية
- دالة الخادم `sendWhatsAppNotification` في `src/lib/whatsapp/notify.functions.ts`
  مع `requireSupabaseAuth` + فحص دور admin للاستخدام اليدوي، ومسار داخلي مباشر للاستخدام التلقائي.
- التحقق من المدخلات بـ Zod (رقم الهاتف، طول النص).
- التوكن يُقرأ داخل الـ handler فقط عبر `process.env`.
- ملاحظة تشغيلية: واتساب لا يسمح برسائل نصية حرة إلا خلال 24 ساعة من آخر رسالة من العميل؛
  خارج ذلك يلزم قالب معتمد. سأضيف دعم إرسال عبر قالب باسم قابل للضبط إن توفر لديك قالب معتمد.
